# The Beauty Studio Granja Viana

Landing page institucional do salão The Beauty Studio (Granja Viana, Cotia/SP) — por Fran Badaroski.

Desenvolvido por Avex Studio.

## Stack

TanStack Start (React 19) · Vite · Tailwind CSS 4 · Nitro (deploy na Vercel)

## Rodar localmente

Requer Node.js 20+.

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Deploy (Vercel)

Importe o repositório na Vercel. Framework preset: **Other** (ou o detectado automaticamente).
Build command: `npm run build` — o Nitro gera a saída da Vercel (`.vercel/output`) automaticamente.
